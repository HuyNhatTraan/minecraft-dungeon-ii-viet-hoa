Đồ hoạ

Chỉnh chất lượng game trực tiếp từ launcher — không cần vào trong game.
⚠ Game đang chạy. Vui lòng THOÁT game rồi vào lại để áp dụng các thay đổi đồ hoạ.

Thông tin

Launcher đóng gói một file exe duy nhất (WebView2).

1. Chọn đường dẫn game → Cài Việt hoá.
2. Vào game → Cài đặt → Ngôn ngữ văn bản → Tiếng Việt.
3. Tab Font tuỳ chỉnh để đổi font TTF/OTF.
4. Lần đầu mở game có thể mất 2-3 phút để nạp shader.
